Integers

INTEGERS

Let’s learn to recognise integers on the number line.

From -5 to 5 Number line
+

1, 2, 3 … these are positive integers. You need not write the + sign.

−

-4, -3, -2, -1 these are negative integers. The - sign must be written in front of them.

0

… -4, -3, -2, -1, 0, 1, 2, 3 … all of these are integers.

↔

Going right along the line, the value increases. Going left, the value decreases.
